# RaceLog — лабораторная работа № 2

Журнал заездов на Windows Forms (.NET 10): записи хранятся объектами, показываются в
таблице, ищутся и фильтруются, сохраняются в SQLite между запусками, а также
копируются в JSON и XML и восстанавливаются из них одной транзакцией.

Работа продолжает ЛР 1 «Журнал заездов»: та же предметная область (пилот, автомобиль,
трасса, время круга), но запись представлена классом `RaceResult`, а данные хранятся
в базе.

## Возможности

- таблица `DataGridView`, связанная с моделью через `BindingSource`;
- добавление, изменение и удаление записей с проверкой ввода;
- поиск по имени пилота без учёта регистра и фильтр по трассе;
- хранение в SQLite (`%LOCALAPPDATA%\RaceLogLab2\racelog.db`) с параметризованными
  запросами;
- сохранение всего журнала в JSON и XML;
- восстановление журнала из копии с полной проверкой и подтверждением;
- замена журнала одной транзакцией: при ошибке прежние данные остаются на месте.

## Требования

- Windows 10/11;
- .NET SDK 10.0 — основная цель (`net10.0-windows`), либо .NET SDK 9.0 для
  Visual Studio 2022: проект автоматически собирается под `net9.0-windows`,
  если SDK 10 не установлен;
- Visual Studio 2022/2026 либо `dotnet` CLI.

Единственная внешняя зависимость — `Microsoft.Data.Sqlite` 10.0.11
(JSON и XML входят в платформу).

## Сборка и запуск

В Visual Studio: откройте `RaceLogLab2.sln` и нажмите F5.

Из командной строки:

```powershell
dotnet build RaceLogLab2.sln
dotnet run --project RaceLog
```

Если установлен SDK 10, проект имеет две цели и команде нужен параметр
`-f net10.0-windows` (или `-f net9.0-windows`). При SDK 9 цель одна, параметр
не требуется.

## Автоматические проверки

```powershell
dotnet run --project Проверки
```

На SDK 10 добавьте `-f net10.0-windows`. Проверки не запускают форму и работают
с временными базами: 37 сценариев для модели, поиска, SQLite, копий JSON/XML и
отката транзакции.

## Учебные данные

Папка `Данные`:

| Файл | Назначение |
| --- | --- |
| `Заезды.json`, `Заезды.xml` | основная копия из шести записей, Id 1–6 |
| `Ошибка времени.json` | копия с временем 601 — должна быть отклонена |
| `Повтор Id.json` | копия с повторяющимся Id — должна быть отклонена |
| `Поврежденная копия.json`, `Поврежденная копия.xml` | нечитаемые файлы |
| `Пустой журнал.json` | корректная пустая копия |

Восстановление: кнопка «Загрузить JSON» или «Загрузить XML», затем подтверждение
замены журнала.
